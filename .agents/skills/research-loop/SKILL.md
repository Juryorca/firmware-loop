# 固件研究主循环

## 适用场景

- 开始或恢复一个 target 的研究轮次；
- 从假设池取队首、推进一个面；
- 判断本轮能否收口、写停止声明、做三镜刷新或收尾。

## 前置

- 已有 target 与权威 SQLite 状态；
- 已读根目录 `AGENTS.md`（全局硬约束优先）；
- 需要完整原文时读 `references/LOOP.md`。

## 启动 / 继续 / 收尾

- **目标为空**：先问用户目标；不要自行猜固件。
- **参数含“继续”**：从 SQLite 的队列/进度/假设池恢复；历史原文只在 SQLite `documents`；单步不重立项、不重提取。
- **参数含“收尾”**：停止新实验 → 知识沉淀（`knowledge_propose` 候选）→ 报告 → CLOSURE →
  `bash tools/derived_check.sh <target> --closure`（FAIL 清零）→ 按 `references/LOOP.md` 清理。
  厂商是 CNA 时不产 MITRE 件。

## 核心步骤

1. **取队首**：只从假设池（唯一队列）取未处理项；面属性只用于排序/过滤。
2. **声明本轮**：开头写 `本轮目标: H-xx`。
3. **建模**：入口、参数、判定点、sink、信任边界、已知保护、推翻条件；没有模型不构造。
4. **构造/验证**：选择与输入结构匹配的格（变异输入/差分/静态审计），记录证据来源。
5. **双输出**：收尾写 `本轮: H-xx → <定论/降级> + 证据` 和 `新观察: ...`；新观察要升成新假设。
6. **三镜**：面/格收口时用 `state_record_mirror` 记机制/作者/状态/新面。
   三镜是**挖掘中途发现、扩展新面**（新入口/端点/状态/配置/版本/同族/解析器/异常行为），
   只收独立可证伪方向；不是把当前单链拆成 H 清单。当前链完善另走本轮 H/next。
7. **停止**：只有本轮新 finding、队列清空、具体外部阻塞、目标级裁决才停；成本/耗时不构成理由。
8. **收尾**：Gate/derived_check 清零，导出报告与 CLOSURE；清理按 `references/LOOP.md`。
   归档释放时，运行载体重建配方写 `report/CLOSURE.md`（交付物内部档案）；对外 attachments README 只写公开获取/参数化步骤，不写 `state/`、`artifacts/` 等内部路径。

## 输入/输出

- 输入：target、当前假设/证据/观察、面属性、预算与授权。
- 输出：本轮结论、观察、三镜记录、停止声明、下一步。

## 失败与边界

- 工具/环境失败先分诊，不写成研究结论；修因后重跑同一格。
- 缺对照只降结论强度，不自动停工。
- 历史 finding 不是本轮停止理由。
- 不得伪造轮次、停止声明、Gate 或证据。

## 验收

- 本轮目标与收口行成对出现；
- 新观察有去向；
- 三镜未超期；
- 停止理由可指认且附证据。
